# Security policy

RollCall handles sensitive attendance and account data. Do not report vulnerabilities through public issues, and never include real student records, account tokens, signing files, or service credentials in a report.

For a private report, use GitHub's **Report a vulnerability** action in the repository's Security tab. Include affected version/commit, impact, and minimal reproduction steps. If that private reporting option is unavailable, contact the repository owner through their GitHub profile and ask for a private reporting channel; do not publish exploit details before a fix is available.

There is no guaranteed response-time commitment. Please allow maintainers a reasonable opportunity to investigate and prepare a fix before public disclosure.
