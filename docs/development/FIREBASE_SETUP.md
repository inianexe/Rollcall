# Firebase Authentication setup

This change prepares the Android and web clients for Google, email-link, and existing password sign-in. Production Firebase settings were not modified. The checked-in Android Firebase config has no OAuth clients, so Google sign-in is intentionally unavailable until the owner completes the Android steps below.

## Google sign-in on Android

1. In Firebase Console, open project **rollcall-ab5d1** → **Authentication** → **Sign-in method** and enable **Google**.
2. Open **Project settings** → **Your apps** → Android app `com.iniexe.rollcall`. Add the SHA-1 and SHA-256 fingerprints for every signing certificate used by local debug, the established release key, and Google Play App Signing if Play distribution is used.
3. Confirm the generated Web OAuth client is present. Use that Web client ID as `default_web_client_id` through the updated `google-services.json` generated by Firebase; do not copy a client secret into the app.
4. Replace the local/configuration-managed Android Firebase config with the owner-approved file and verify it contains a non-empty `oauth_client` list and the correct package/project. Do not commit private service-account keys; the client config contains public identifiers but should still follow the repo's configuration policy.
5. Build and test on a non-production install with a controlled Firebase account. Check both first-time sign-in and provider linking, and confirm the Firebase UID remains unchanged when linking.

## Email-link sign-in (Android and web)

1. In Firebase Console → **Authentication** → **Sign-in method**, enable **Email/Password** and the **Email link (passwordless sign-in)** option. Keeping Email/Password enabled preserves current password users and password reset.
2. In **Authentication** → **Settings** → **Authorized domains**, verify the Firebase Hosting action-link domain and the production web host (`rollcall-campus-companion.pages.dev`) as required by the Firebase SDK configuration.
3. Confirm Firebase Hosting's default `PROJECT_ID.firebaseapp.com` action handler is available. Android requests use `https://rollcall-ab5d1.firebaseapp.com` and the manifest claims `/__/auth/links` with App Links; verify the Firebase app's package and signing fingerprints for link dispatch.
4. On Android, test same-device completion, email re-entry after app data loss, expired/reused link messaging, and reauthentication before deleting an email-linked account.
5. On web, test email-link completion in the same browser and a second browser where the user must enter the email address. Do not put email addresses, passwords, or ID tokens in continuation URLs.

Firebase's supported Android flow and requirements are documented in [Google sign-in](https://firebase.google.com/docs/auth/android/google-signin) and [email-link authentication](https://firebase.google.com/docs/auth/android/email-link-auth); browser completion is in [Firebase Web email-link auth](https://firebase.google.com/docs/auth/web/email-link-auth).

## Web Google configuration

Verify the Firebase web app config in the deployment environment, the project's OAuth authorized origins, and the authorized domain for the deployed website. The web client uses Firebase `signInWithPopup`; test popup blocking and provider conflicts in supported browsers. Do not change production OAuth settings without the project owner's review.

## Verification checklist

- Confirm Firebase project ID `rollcall-ab5d1` and Android package `com.iniexe.rollcall`.
- Verify provider switches and authorized domains in Console before claiming a method is enabled.
- Keep the Admin SDK private key and Resend key only in Cloudflare secrets; never add them to Android, web config, docs, or Git.
- Exercise provider linking with synthetic accounts and record the UID before and after.
- Validate the Android App Link with the signed artifact that will be distributed. Debug and release certificates differ.
- Run Android unit tests and web API tests, then separately perform controlled device and staging tests. Local tests do not contact Firebase or production services.
