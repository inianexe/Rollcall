# Rollcall v0.9.2 — Clearer Chrome Installation

Download **rollcall-v0.9.2-browser.zip**, extract it, then select the **rollcall-extension folder** using Chrome/Edge → Extensions → Developer mode → Load unpacked.

**Chrome's picker hides files. You should select the folder, not manifest.json.** Firefox's Load Temporary Add-on instead selects the manifest.json file.

- One clearly named browser installation folder.
- Manifest and declared script/icon validation during packaging.
- SHA-256 checksum supplied alongside the browser ZIP.
- README includes exact folder selection for release and source-code downloads.
- Attendance and timetable functionality retained. Android excluded.

This supersedes the mixed v0.9 release assets. Historical screenshots show v0.9.1. Package/unit checks are separate from live browser compatibility checks.
